## План

1. Санитайзер имени + валидатор `dur` + белый список сигнатур (6 форматов, копия
   приёмникового) в блоке лиги.
2. Отправка: вложение по сигнатуре, а не «только webp»; `dur` и `name` пробросом.
3. Чтение: `gseq` числом в запрос к приёмнику.
4. Отдача: белый список расширений → путь из числа и расширения; тип по сигнатуре только
   для проверенных байтов; иначе `octet-stream` + `attachment` + `filename` и `filename*`;
   `If-None-Match`/`ETag`/304 насквозь; сутки кеша снять.
5. Тесты: проброс полей, санитайзер, `gseq`, заголовки по каждой ветке, четыре обхода
   каталога. Мутации на пункты 3–4 брифа.

   Понадобится для текста отказа — это одна строка в `handleLeagueChatPost`.
3. Частные пределы (звук 512 КиБ, файл 512 КиБ) живут только у приёмника; у хаба одна внешняя
   рамка 2 МиБ (`LEAGUE_ATT_MAX_BYTES`, равна `MAX_ATT`). Поменяется `MAX_ATT` — менять и её.
4. `Cache-Control` наружу — `no-cache`, а не приёмниковый `no-store`: `no-store` запрещает
   хранить, а значит убивает и условный запрос вместе с 304. Арифметика в комментарии
   `leagueAttCacheHead`.
5. Седьмой формат — это строка в `LEAGUE_ATT_MIME` хаба И строка в `ATT_KIND`/`ATT_SNIFF`
   приёмника. Расхождение теперь ловится проверкой «таблица типов хаба совпадает с ATT_KIND».
