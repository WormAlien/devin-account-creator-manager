## Доработка по замечаниям приёмника (05.09, вечер)

Приёмник дописан и выкачен, форма надгробий и раскладка вложений изменились. Что сделано:

- [x] **`mkTombs` переписан под согласованную форму** `{ v:2, gseq, cut, tombs:[{seq, at: ISO, why, gseq}] }`.
      Основной путь — объект, запасные — `{gone:[…]}` и голый массив первой версии.
      🔴 `gseq` и `cut` переносятся КАК ЕСТЬ, в функции нет ни одного `++` над ними:
      курсор ниже запомненного клиентами = «перечитай хвост» у всех сразу.
      Номера назначаются только записям, у которых своего `gseq` нет (файл первой
      версии) — и ВЫШЕ всего известного, потому что вверх безопасно, вниз нет.
      Время всегда приводится к ISO-строке: приёмник фильтрует по `Date.parse(at)`,
      и число миллисекунд (форма первой версии) он бы молча отбросил.
      В файл уезжают только четыре поля контракта, диагностика — отдельным объектом.
- [x] **Три каталога вложений вместо одного:** `att/` (30 суток), `voice/` (7), `files/` (30).
      Каждый переезжает в `<каталог>/<gid>/`, имя файла не меняется, **байты сверяются
      после переноса у каждого файла** (не «переименование не портит по определению»).
      Куда попадает файл, решает расширение — таблица повторена из приёмника
      (`attHome`), маска имени расширена до `[a-z0-9]{1,8}`: прежняя
      `webp|webm|ogg|m4a|mp3|wav` оставила бы `files/844.pdf` лежать молча.
- [x] **Проверка «не осталось файлов прежней раскладки» больше не про один `att/`** —
      она считает по всем трём (`attLeftCount`), и то же в `pending()` и в откате.
      Ожидаемый путь вложения в журнале теперь несёт свой каталог (`voice/841.webm`),
      поэтому врать при появлении четвёртого каталога ей нечем.
- [x] Итоговая строка выката несёт `tombs=` и `gseq=`; в выкате после перехода названа
      приёмка чистки (правило указывает на каталог, а файлы теперь на уровень глубже —

## Формы файлов (актуальное)

- `members.json` — карта `memberId → { memberId, tokenHash, installId, nick, groups[], status, createdAt, invitedBy }`
- `groups.json` — карта `gid → { gid, title, createdBy, createdAt, members[] }`
- `invites.json` — пустая карта `{}` (ключ = хеш кода)
- `chat/<gid>.tombs.json` — `{ v: 2, gseq, cut, tombs: [{ seq, at: ISO, why, gseq }] }` — **согласовано с приёмником**
- `addr-salt` — 64 hex-символа, соль для `addrTag` вместо секрета
- вложения — `att/<gid>/<seq>.<ext>`, `voice/<gid>/<seq>.<ext>`, `files/<gid>/<seq>.<ext>`

`chat-gone.json` НЕ удаляется намеренно: источник цел — надгробия можно пересобрать.
