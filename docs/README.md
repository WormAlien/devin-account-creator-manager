# docs/ — что здесь лежит

Список нужен ровно затем, чтобы больше не приходилось спрашивать «а этот хендофф ещё
актуален и кому его слать». Слово **«хендофф» оставлено одному файлу** — тому, который
действительно передаётся человеку. Всё остальное названо тем, чем является: гайд, концепт,
архив.

## Живое

| файл | что это | кому |
|---|---|---|
| [`HANDOFF-upstream-keepalive.md`](HANDOFF-upstream-keepalive.md) | **единственный настоящий хендофф** — что мы починили в `keepalive-proxy.js` и не отдали автору апстрима (`v1tusha/life-support`) | Вите, внешнему человеку |
| [`setup-everything-search.md`](setup-everything-search.md) | гайд: быстрый поиск файлов через индекс Everything | себе, при установке на новую машину |
| [`MAC-SETUP.md`](MAC-SETUP.md) | установка стенда на macOS | себе / второму пользователю |
| [`STATUSLINE.md`](STATUSLINE.md) | статуслайн Claude Code: формат, диагностика | себе |
| [`frontdoor-concept.md`](frontdoor-concept.md) | замысел front-door `:20100` и контракт прокси. **Реализовано** — за фактическим состоянием идти в `ARCHITECTURE.md` | тому, кто правит `frontdoor-proxy.js` |

Каноничное описание системы — `ARCHITECTURE.md` в корне, а не файлы отсюда. Ручки
keepalive — `routing/KEEPALIVE-TUNING.md`.

## `archive/` — исполнено или отменено

Лежит как история вопроса: зачем делали и что выяснили по ходу. **Как инструкция к
действию не годится** — сверяться только с `ARCHITECTURE.md`. Имена оставлены прежними,
чтобы старые ссылки и `grep` по ним продолжали находить.

| файл | было | статус |
|---|---|---|
| `archive/HANDOFF-model-1m.md` | разбор: окно 200k вместо 1M из-за потери суффикса `[1m]` | закрыто, сторож — `tools/check-1m.js` |
| `archive/BALANCE-CHECK-HANDOFF.md` | ТЗ на чек баланса AgentRouter | исполнено |
| `archive/SESSION-LK-HANDOFF.md` | ТЗ на кнопку «ЛК» | исполнено |
| `archive/RAG-ONDEMAND-HANDOFF.md` | ТЗ на on-demand RAG/Ollama | отменено, стек снят 2026-08-17 |

## Правило на будущее

Прежде чем назвать файл хендоффом — проверить, есть ли **человек**, которому он
передаётся. Если это записка себе или следующей сессии, это ТЗ или гайд; когда сделано —
переезжает в `archive/` с честным статусом в первых строках. Иначе повторится то же:
шесть «хендоффов» рядом, пять мертвы, один врал про свой статус («не реализовано» у давно
работающего front-door), и понять со стороны, какой из них живой, невозможно.
