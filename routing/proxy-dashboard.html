    Режим по умолчанию. Один адрес на все клиенты: ANTHROPIC_BASE_URL перестаёт меняться, активный бэкенд живёт в ~/.claude/active-backend.json, а выбор делает локальный прокси routing/frontdoor-proxy.js.     Статус-бар Claude Code

    Строка внизу CC: [провайдер] модель · квота · контекст. Скрипт — routing/statusline-autoreger.sh, реальные окна контекста моделей зашиты в нём (проба — routing/ctx-probe.sh). Применяется со следующего сообщения в сессии.

    Автокомпакт CC

    CC сам сжимает историю при ~78% своего представления об окне (200k для opus без [1m]) — на 1M-бэкендах срабатывает сильно рано. Выключено = компактишь вручную /compact, ориентируясь на шкалу ⧉ в статус-баре.
